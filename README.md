# PrepHub

A personal preparation and study web app for learning, revision, and interview preparation.

## Tech Stack

- React 19
- Vite 8
- React Router 7
- Tailwind CSS 4
- localStorage for persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Features

- Topic-based learning pages (React, JS, CSS, Java, etc.)
- DSA topic pages with pattern-based organization
- Learning Mode / Interview Mode toggle
- Dark / Light theme
- Global search (Ctrl+K)
- Bookmarks
- Recently viewed tracking
- Progress tracking
- Responsive design (mobile + desktop)
- Offline-ready (PWA planned)
